Executive findings

  • 4,477 duplicate track IDs were removed; missing descriptive fields were labeled Unknown.
  • The selected K-Means model uses k=2, the highest sampled silhouette score among k=2–7 (0.170).
  • Clusters represent audio-character similarity, while playlist genre and name show how Spotify’s editorial labels overlap those sounds.
  • Recommendation candidates are nearest songs in standardized audio-feature space within the same cluster.

Workflow

Source CSV → remove duplicate tracks and fill labels → standardize ten audio features → test K-Means k=2–7 → select k by silhouette score → profile clusters and find nearby songs.
